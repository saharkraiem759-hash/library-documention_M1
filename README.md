# Library Management System Documentation (M1)

## Project Overview
This repository documents and analyzes the open-source **[sumitkumar1503/librarymanagement](https://github.com/sumitkumar1503/librarymanagement)** system built with *Python and Django, fulfilling the Milestone 1 (M1) deliverables for the Software Documentation course at **Aqaba University of Technology*.

## Author & Contributions
- *Student / Author:* Sahar (saharkraiem759-hash).

## System Components, Scope, and Boundaries
- *Key Components:*
  - library/: Core library application logic (books, members/students, borrowing and returning workflows).
  - librarymanagement/: Main Django project settings and routing (settings.py, urls.py).
  - templates/ and static/: User interface templates (HTML) and styling/assets.
  - manage.py and requirements.txt: Application execution and dependency management.
- *In Scope:* Analyzing the source code, running the system locally, inventorying existing documentation, performing a documentation gap analysis, and creating a documentation plan aligned with *IEEE 830 / IEEE 29148*.
- *Out of Scope:* Modifying the original system source code or implementing new software features during this milestone.

## Selected Reference Standard
*IEEE 830 / IEEE 29148* is selected to guide the Software Requirements Specification (*SRS*), as the source repository lacks formal requirements documentation and the standard provides a clear, structured fit for the system's scale.
